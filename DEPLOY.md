# Deploy version 1.4.0

The existing Netlify GitHub connection publishes main automatically. Deploy the entire package with netlify.toml at repository root. No environment changes or Render rebuild are required for this update: the existing v0.7.0 server supports detect:true and /health.

Use the existing service access password with Connect service. Select Remember for this browser tab if desired, then select Writing patterns & watermark tests and Review document.
